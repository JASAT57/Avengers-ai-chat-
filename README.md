# Avengers AI Chat — iPhone'a hazır

## Sunucu
Node.js 20+ önerilir.

npm install
cp .env.example .env
# .env içindeki OPENAI_API_KEY değerini kendi anahtarınla değiştir
npm start

Sonra HTTPS altında yayınla.

## iPhone
Safari'de siteni aç -> Paylaş -> Ana Ekrana Ekle.

API anahtarını iPhone/web koduna koyma; yalnızca sunucuda environment variable olarak tut.
